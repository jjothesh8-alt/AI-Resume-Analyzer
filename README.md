# 📄 AI Resume Analyzer & ATS Score Checker

A beginner-friendly AI-powered web application that compares a student's resume against a job description and returns an ATS match score, matching skills, missing skills, and five actionable suggestions for improvement.

Built with **Python**, **Streamlit**, and the **Google Gemini API**.

---

## 🚀 Features

| Feature | Detail |
|---|---|
| PDF Upload | Upload your resume as a PDF; text is extracted automatically |
| Job Description | Paste any job posting |
| ATS Score | A score out of 100 showing how well your resume matches |
| Matching Skills | Skills found in both your resume and the job description |
| Missing Skills | Keywords in the job posting not found in your resume |
| Suggestions | Five specific, actionable tips to improve your resume |

---

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| Python 3.9+ | Programming language |
| Streamlit | Web application UI |
| Google Gemini API (`google-genai`) | AI analysis engine |

## ⚙️ Setup Instructions (Step by Step)

### Step 1 — Get a Gemini API Key

1. Go to [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
2. Sign in with your Google account
3. Click **Create API Key**
4. Copy the key

### Step 2 — Add Your API Key

Open the `.env` file in the project folder and replace the placeholder:

```
GEMINI_API_KEY=your_actual_key_here
```

Save the file. **Never share or upload this file.**

### Step 3 — Install Dependencies

Open a terminal (Command Prompt or PowerShell) in the project folder and run:

```bash
pip install -r requirements.txt
```

### Step 4 — Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your browser at `http://localhost:8501`.

---

## ☁️ Deploying to Streamlit Cloud (Optional)

1. Push this project to a GitHub repository (**make sure `.env` is listed in `.gitignore`**)
2. Go to [https://streamlit.io/cloud](https://streamlit.io/cloud)
3. Connect your GitHub repo
4. Under **Secrets**, add:
   ```toml
   GEMINI_API_KEY = "your_actual_key_here"
   ```
5. Click **Deploy**

---

## 🔐 Security Notes

- The API key is read from `.env` locally and from Streamlit Secrets on the cloud.
- The key is never displayed in the app.
- Uploaded PDFs are read into memory and never saved to disk.
- `.env` is listed in `.gitignore` to prevent accidental uploads.

## ⚠️ Important Notes

- PDFs that are **scanned images** (not text-based) cannot be read by pypdf. Use a text-based PDF.
- Results are generated by AI and should be used as a guide, not a definitive evaluation.
- The free Gemini API tier has rate limits. If you hit a limit, wait a minute and try again.
